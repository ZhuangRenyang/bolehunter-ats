## 一、产品定位（不变项）

为 **5–20 人小型猎头团队**打造的轻量级 ATS + CRM：

- **北极星指标**：每周有效推荐数
- **角色模型**：管理员 + 顾问（企业与 HR 是数据对象，不是登录账号）
- **部署承诺**：单机 2C4G、10 分钟能用、Docker Compose 一键起
- **商业边界**：开源版 = 完整作业闭环；闭源 SaaS 部署走商业授权（Open Core）

## 三、短期计划（v1.1，1–2 个月）

## 四、中期计划（v1.2 – v1.4，3–6 个月）

- [x] **简历 AI 解析（迭代 19）**：`resume_parse` 开关正式接线（首次业务化使用功能开关）——开关开且 `AI_API_KEY` 已配置时走 LLM 结构化抽取（OpenAI 兼容协议，DeepSeek/通义等，`AI_BASE_URL/AI_MODEL/AI_API_KEY` 环境变量注入，Key 不进代码库），抽取 7 字段仅覆盖非空值（规则高置信字段不被冲掉）；Key 缺失/调用失败静默降级本地规则解析（迭代2 行为不变）；JSON 容错（markdown 围栏/前后缀噪声）；5 个单测
- [x] **AI 配置后台化（迭代 19+，用户建议）**：`app_setting` 键值表 + 管理员后台「AI 服务配置」页（base_url/model/embedding_model/API Key），数据库优先、环境变量兜底、API Key 回显脱敏、留空提交保持不变——非开发用户零命令行使用
- [x] **AI 找人问答（迭代 20，RAG）**：`ai_ask` 开关控制；导入简历保存全文（resume_text）作为检索语料；检索优先向量语义（embeddings 预计算 + 余弦 top5，供应商需支持 /embeddings）、自动降级关键词检索；LLM 归纳回答（强制引用来源、不编造），LLM 不可用时优雅返回命中列表；管理员可重建向量索引
- [x] **数据看板增强（迭代 14）**：漏斗时间对比（近 30 天 vs 前 30 天分组柱图）、顾问业绩排行（本自然月推荐/已读/面试/Offer/回款）、客户转化率报表（按公司 + 回款转化率进度条 + CSV 导出）；统计改为 SQL 聚合（GROUP BY + MySQL 时间窗口，替换原 LIMIT 2000 内存分组）
- [ ] **操作审计增强**：敏感操作（删除客户/候选人）二次确认 + 审计流水独立查询页
- [x] **WebSocket 实时协作（迭代 23）**：路线图原条目为「老系统残留能力，重建或正式移除」——决策为**重建**。清除 2022 年旧求职项目的残留代码（8 个 WS 类 + ChatService/ChatDO/ChatMapper + `chat` 表；旧端点 `/ws/message/{uID}` 用路径参数自称身份、无任何鉴权，改个数字即可冒充任意用户）后重写：握手用同一套 JWT 验签取 `identity`（`/recruit/ws?token=`），浏览器无法自定义请求头故令牌走查询参数；`im_message` 表落库 + WebSocket 实时送达双写（先入库再推送，收件方离线不丢消息）；内部单聊（会话列表/历史/未读/已读回执）；**顺带把通知中心接进来**——此前 `notify` 只在身份权限校验失败时才可能加载，铃铛角标恒为 0，现改为首次加载 + WS 实时增量刷新 + 60s 轮询兜底；`im_realtime` 开关控制，关闭时不影响既有行为；Nginx 与 Vite 代理同步支持 Upgrade 头
- [ ] **国际化骨架**：前端 i18n 抽取（中/英），为潜在海外团队铺路
- [x] **性能加固（迭代 17）**：Element Plus 按需引入（unplugin-vue-components/auto-import resolver + v-loading 手动注册 + 指令式样式手动引入 + 图标白名单注册 22 个，替换全量约 300 个）；ECharts 按需（echarts/core 仅注册柱图/漏斗）；第三方库独立 chunk——构建产物 index.js 1.3MB→272KB（-79%）、workbench.js 1.1MB→116KB（-89%）
- [ ] **列表虚拟滚动、慢查询索引梳理**：数据量增长后评估

## 七、版本与发布策略

- **语义化版本**：v1.1.0 / v1.2.0 功能版；破坏性变更进 v2.0.0
- **双平台同步**：GitHub 为主开发；Gitee 仓库页"强制同步"一键对齐（或本地 `git push gitee main`）
- **发布节奏**：短计划每 2–3 周一个功能版；每个功能版必须含：编译/构建绿 + 冒烟通过 + 文档更新（README 功能清单、开发记录日志、本路线图勾选）
