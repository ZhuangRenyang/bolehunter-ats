# 部署指南

> 项目：**BoleHunter 伯乐猎** —— 开源猎头 ATS + CRM
> 仓库：https://github.com/ZhuangRenyang/bolehunter-ats ｜ https://gitee.com/ZhuangRenyang/bolehunter-ats
> 目标：**10 分钟能用**，单机 2C4G 即可运行。

## 〇、Docker Compose 一键部署（推荐，迭代16）

只需安装 Docker（含 compose 插件），无需 JDK/Maven/Node/MySQL/Redis：

```bash
git clone https://github.com/ZhuangRenyang/bolehunter-ats.git
cd bolehunter-ats
cp .env.example .env          # 按需修改 DB_PASSWORD / JWT_SECRET / CORS_ORIGINS
docker compose up -d          # 首次构建约 5-10 分钟
docker compose ps             # 四个容器 healthy/running 即就绪
```

- 访问 `http://localhost:8080`，默认账号 `root / 123456`（**首次登录立即修改**）
- 架构：`frontend(nginx:80)` 反代 `/recruit/**` 与 `/assets/**` 到 `backend(5000)`，同源无跨域；`mysql8` 首次启动自动按序执行 `sql/` 初始化脚本；`redis7` 存限流计数与验证码
- 时区统一东八区（MySQL `default-time-zone=+08:00` + 容器 `TZ=Asia/Shanghai`）
- 生产上线：在 `.env` 中设置强随机 `JWT_SECRET`（`openssl rand -hex 32`）、真实域名 `CORS_ORIGINS`、改默认 `DB_PASSWORD`；建议 nginx 层再挂 HTTPS
- 常用命令：`docker compose logs -f backend`（看日志）、`docker compose down`（停）、`docker compose down -v`（停并清空数据，慎用）

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| JDK | 17+ | 后端编译与运行 |
| Maven | 3.8+ | 后端构建 |
| Node.js | 18+ | 前端构建 |
| MySQL | 8.0+ | 字符集 utf8mb4 |
| Redis | 6+（可选） | 仅聊天/通知模块使用，核心 ATS 流程不依赖 |

## 二、本地启动（开发模式）

### 1. 初始化数据库

```bash
mysql -uroot -p < bolehunter-ats/sql/bolehunter.sql          # 基线（含 CREATE DATABASE）
mysql -uroot -p bolehunter < bolehunter-ats/sql/migration_iter0_ats.sql
mysql -uroot -p bolehunter < bolehunter-ats/sql/migration_iter1_crm.sql
mysql -uroot -p bolehunter < bolehunter-ats/sql/migration_iter2_candidate.sql
mysql -uroot -p bolehunter < bolehunter-ats/sql/migration_iter3_recommendation.sql
mysql -uroot -p bolehunter < bolehunter-ats/sql/migration_iter4_communication.sql
```

> ⚠️ 每个迁移脚本只执行一次；`bolehunter.sql` 基线内含默认账号（root / 123456）。

### 2. 修改后端数据库配置

编辑 `bolehunter-ats/src/main/resources/application-dev.yml`：

```yaml
spring:
  datasource:
    username: root
    password: 你的密码
    url: jdbc:mysql://127.0.0.1:3306/bolehunter?useSSL=false&serverTimezone=UTC&characterEncoding=UTF8&allowPublicKeyRetrieval=true
```

### 3. 启动后端（端口 5000）

```bash
cd bolehunter-ats
mvn compile spring-boot:run -Dspring-boot.run.arguments="--server.port=5000"
# Windows 环境注意：插件已内置 -Dfile.encoding=UTF-8
```

启动成功标志：日志出现 `Started RecruitApplication`。

### 4. 启动前端（端口 8081）

```bash
cd bolehunter-ats-web
npm install --registry=https://registry.npmmirror.com
npm run dev
```

### 5. 登录

浏览器打开 `http://localhost:8081`，默认账号 **root / 123456**（请登录后立即在用户管理改密）。

## 三、Docker Compose 部署（推荐生产/演示）

> 需要先进容器打包镜像：后端 `Dockerfile`（JDK17 基础镜像 + mvn package 产物）、前端构建产物由 Nginx 托管并反代后端。

```yaml
# docker-compose.yml（示意，首次使用前请结合实际调整）
version: "3.8"
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: bolehunter
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_general_ci
    volumes:
      - mysql_data:/var/lib/mysql
      - ./bolehunter-ats/sql:/docker-entrypoint-initdb.d:ro   # 首次启动自动执行基线+迁移脚本（按文件名排序）
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-uroot", "-p${MYSQL_ROOT_PASSWORD}"]
      interval: 10s
      retries: 10

  redis:
    image: redis:7-alpine

  backend:
    build: ./bolehunter-ats
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/bolehunter?useSSL=false&serverTimezone=UTC&characterEncoding=UTF8&allowPublicKeyRetrieval=true
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      SPRING_DATA_REDIS_HOST: redis
      JAVA_TOOL_OPTIONS: -Dfile.encoding=UTF-8
    depends_on:
      mysql:
        condition: service_healthy
    ports:
      - "5000:5000"

  frontend:
    build: ./bolehunter-ats-web
    depends_on:
      - backend
    ports:
      - "8081:80"
volumes:
  mysql_data:
```

**要点**：
- 初始化 SQL 放入 `docker-entrypoint-initdb.d` 会按文件名字典序执行（bolehunter.sql → migration_iter0…4 天然有序）
- 后端容器内 `JAVA_TOOL_OPTIONS` 强制 UTF-8（Windows 主机经验同样适用于容器）
- 前端镜像内 Nginx 需配置 `/recruit` 与 `/assets` 反代到 `backend:5000`
- 生产环境务必：修改默认密码、MySQL 数据卷持久化、CORS 收紧为实际域名

## 四、备份

```bash
mysqldump -uroot -p --single-transaction bolehunter > backup_$(date +%F).sql
```

简历原件位于后端 `assets/resume/` 目录，需一并备份。
